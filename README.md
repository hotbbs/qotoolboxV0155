# Quantum Optics Toolbox for MATLAB (v0.155)

This directory contains the **Quantum Optics Toolbox** (version 0.155) for MATLAB, which is used as a dependency in our numerical simulations.

## 👨‍💻 Original Author
This toolbox was developed by **Sze M. Tan** (University of Auckland, New Zealand). 
It is widely used in the quantum optics community for solving quantum master equations and computing open quantum system dynamics.
